🛡️ What's private?

✓
Model inference stays on-device

Prompts and replies are processed by the iPhone GPU. The app itself does not send them to a chat API.

!
Initial downloads need internet

The runtime and weights come from external providers. Browsers can evict cached files, and hosting services see normal website requests.

!
No background hosting

iOS can suspend apps, so this cannot run as a public, always-on API server.
